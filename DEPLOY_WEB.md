# Highway Pilot Web Deployment

This project is now prepared for public web deployment with:
- Backend API on Render
- Frontend app on Vercel

## 0) Current Deployment State

- [render.yaml](render.yaml) is configured for a production Docker deploy with health check at /api/ai/health.
- [pilot-web/vercel.json](pilot-web/vercel.json) is configured for SPA routing.
- Frontend API calls are environment-based through [pilot-web/src/lib/api.js](pilot-web/src/lib/api.js).

## 1) Push to GitHub

Create or update your GitHub repo and push the latest code.

## 2) Deploy Backend on Render

1. Open Render dashboard.
2. Click New + and select Blueprint.
3. Select your GitHub repo.
4. Render will load [render.yaml](render.yaml) and create:
   - Web service: pilotapp
   - Postgres database: pilot-db
5. In the web service Environment tab, set values for any variables marked manual:
   - OPENAI_API_KEY (required)
   - ANTHROPIC_API_KEY (optional)
   - CORS_ORIGINS (temporary value: ["http://localhost:5173"]) 
6. Deploy and copy your API URL.

Expected health endpoint:
- https://YOUR-RENDER-API.onrender.com/api/ai/health

## 3) Deploy Frontend on Vercel

1. Open Vercel dashboard.
2. Import the same GitHub repo.
3. Set project root directory to:
   - pilot-web
4. Set environment variable in Vercel Project Settings:
   - VITE_API_BASE_URL = https://YOUR-RENDER-API.onrender.com
5. Deploy.

## 4) Configure CORS on Render

After Vercel gives your frontend URL, set this in Render:

CORS_ORIGINS value example:
["https://your-frontend.vercel.app"]

Then redeploy backend.

If you use a custom domain, include both domains:
["https://your-frontend.vercel.app","https://www.yourdomain.com"]

## 5) Verify Public Production

Frontend:
- https://your-frontend.vercel.app

Backend health:
- https://YOUR-RENDER-API.onrender.com/api/ai/health

AI smoke check example:
- POST https://YOUR-RENDER-API.onrender.com/api/ai/chat?session_id=prod-test&message=hello

## Required vs Optional Environment Variables

Set these in Render web service:

Required:
- OPENAI_API_KEY
- SECRET_KEY (auto-generated by render.yaml)
- CORS_ORIGINS

Recommended:
- ANTHROPIC_API_KEY
- APP_ENV=production
- DEBUG=false
- AI_MOCK_MODE=false

Optional for advanced features:
- REDIS_URL
- PINECONE_API_KEY
- GOOGLE_MAPS_API_KEY
- CELERY_BROKER_URL
- CELERY_RESULT_BACKEND

## Notes

- Redis and Postgres are optional to get started publicly; app can run without them for early demos.
- For production reliability, add managed Postgres and Redis services in Render and set DATABASE_URL and REDIS_URL.

## One-Pass Publish Checklist

1. Push code to GitHub.
2. Deploy Render Blueprint from [render.yaml](render.yaml).
3. Wait for green health at /api/ai/health.
4. Deploy Vercel project from pilot-web.
5. Set VITE_API_BASE_URL in Vercel.
6. Copy Vercel URL into Render CORS_ORIGINS.
7. Redeploy Render.
8. Validate chat endpoint and frontend interactions publicly.
