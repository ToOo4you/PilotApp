# Highway Pilot Web Deployment

This project is now prepared for public web deployment with:
- Backend API on Render
- Frontend app on Vercel

Use this document as the source of truth for production release.

## 0) Current Deployment State

- [render.yaml](render.yaml) is configured for a production Docker deploy with health check at /api/ai/health.
- [pilot-web/vercel.json](pilot-web/vercel.json) is configured for SPA routing.
- Frontend API calls are environment-based through [pilot-web/src/lib/api.js](pilot-web/src/lib/api.js).

## 1) Push to GitHub

Create or update your GitHub repo and push the latest code.

## 2) Deploy Backend on Render

1. Open Render dashboard.
2. Click New + and select Blueprint.
3. Select your GitHub repo.
4. Render will load [render.yaml](render.yaml) and create:
   - Web service: pilotapp
   - Postgres database: pilot-db
5. In the web service Environment tab, set values for any variables marked manual:
   - OPENAI_API_KEY (required)
   - ANTHROPIC_API_KEY (optional)
   - CORS_ORIGINS (production value: ["https://www.highwaypilotai.com"]) 
6. Deploy and copy your API URL.

Expected health endpoint:
- https://YOUR-RENDER-API.onrender.com/api/ai/health

## 3) Deploy Frontend on Vercel

1. Open Vercel dashboard.
2. Import the same GitHub repo.
3. Set project root directory to:
   - pilot-web
4. Set environment variable in Vercel Project Settings:
   - VITE_API_BASE_URL = https://YOUR-RENDER-API.onrender.com
5. Deploy.

Important:
- Vercel config no longer proxies API routes to a hardcoded Render hostname.
- The frontend must use VITE_API_BASE_URL in each environment.

## 4) Configure CORS on Render

After Vercel gives your frontend URL, set this in Render:

CORS_ORIGINS value example:
["https://www.highwaypilotai.com"]

Then redeploy backend.

For this project, use the canonical domain:
["https://www.highwaypilotai.com"]

## 5) Verify Public Production

Frontend:
- https://www.highwaypilotai.com

Backend health:
- https://YOUR-RENDER-API.onrender.com/api/ai/health

AI smoke check example:
- POST https://YOUR-RENDER-API.onrender.com/api/ai/chat?session_id=prod-test&message=hello

## Required vs Optional Environment Variables

Set these in Render web service:

Required:
- OPENAI_API_KEY
- SECRET_KEY (auto-generated by render.yaml)
- CORS_ORIGINS
- BILLING_MOCK_MODE=false

Recommended:
- ANTHROPIC_API_KEY
- APP_ENV=production
- DEBUG=false
- AI_MOCK_MODE=false

Optional for advanced features:
- REDIS_URL
- PINECONE_API_KEY
- GOOGLE_MAPS_API_KEY
- CELERY_BROKER_URL
- CELERY_RESULT_BACKEND

Stripe (required only for real paid subscriptions):
- STRIPE_SECRET_KEY
- STRIPE_WEBHOOK_SECRET
- STRIPE_PRICE_ID_STARTER
- STRIPE_PRICE_ID_PROFESSIONAL
- STRIPE_PRICE_ID_ENTERPRISE

## Notes

- Redis and Postgres are optional to get started publicly; app can run without them for early demos.
- For production reliability, add managed Postgres and Redis services in Render and set DATABASE_URL and REDIS_URL.

## 6) Publish Through Wix (Runnable + Monetized)

Use Wix as your marketing and sales site, while Highway Pilot runs in your deployed app.

1. Deploy backend on Render and frontend on Vercel first.
2. In Wix, connect your custom domain (for example: `www.highwaypilotai.com`).
3. Add a CTA button in Wix that links to your live landing page:
   - `https://www.highwaypilotai.com?view=landing`
4. In Render, set `CORS_ORIGINS` to include all domains that may call the API directly:
   - `[`"https://www.highwaypilotai.com"`, `"https://YOUR-WIX-DOMAIN"`, `"https://YOUR-WIX-SITE.wixsite.com"`]`
5. Keep Stripe environment variables configured in Render:
   - `STRIPE_SECRET_KEY`
   - `STRIPE_WEBHOOK_SECRET`
   - `STRIPE_PRICE_ID_STARTER`
   - `STRIPE_PRICE_ID_PROFESSIONAL`
   - `STRIPE_PRICE_ID_ENTERPRISE`
6. In Stripe, configure webhook endpoint:
   - `https://YOUR-RENDER-API.onrender.com/subscriptions/webhook`
7. Publish Wix site and verify purchase flow:
   - User clicks Subscribe on Wix
   - User lands on Highway Pilot pricing page
   - Stripe checkout completes
   - User returns with `?subscribed=true` and plan state displays in app

### Optional: Embed App Section In Wix

You can use a Wix Embed/HTML block and iframe the web app:

```html
<iframe
  src="https://www.highwaypilotai.com"
  style="width:100%;height:900px;border:0;"
  loading="lazy"
  title="Highway Pilot"
></iframe>
```

For best conversion, keep pricing and checkout in the full app page rather than deep iframe nesting.

## One-Pass Publish Checklist

1. Push code to GitHub.
2. Deploy Render Blueprint from [render.yaml](render.yaml).
3. Wait for green health at /api/ai/health.
4. Deploy Vercel project from pilot-web.
5. Set VITE_API_BASE_URL in Vercel.
6. Set Render CORS_ORIGINS to ["https://www.highwaypilotai.com"].
7. Redeploy Render.
8. Validate chat endpoint and frontend interactions publicly.

## Release Checklist (Production)

1. Render environment:
   - APP_ENV=production
   - DEBUG=false
   - AI_MOCK_MODE=false
   - BILLING_MOCK_MODE=false
2. CORS has only production domains.
3. Stripe webhook endpoint is configured:
   - https://YOUR-RENDER-API.onrender.com/subscriptions/webhook
4. Vercel environment has VITE_API_BASE_URL set to Render API URL.
5. Run local validation command:
   - powershell -ExecutionPolicy Bypass -File .\\DEPLOY_VALIDATE.ps1
6. Run public validation command after deploy:
   - powershell -ExecutionPolicy Bypass -File .\\DEPLOY_VALIDATE.ps1 -ApiBaseUrl https://YOUR-RENDER-API.onrender.com -WebBaseUrl https://www.highwaypilotai.com

## Environment Matrix

Development (local):
- APP_ENV=development
- AI_MOCK_MODE=true
- BILLING_MOCK_MODE=true
- CORS_ORIGINS allows localhost

Production (Render + Vercel):
- APP_ENV=production
- AI_MOCK_MODE=false
- BILLING_MOCK_MODE=false
- CORS_ORIGINS includes only live frontend origins
